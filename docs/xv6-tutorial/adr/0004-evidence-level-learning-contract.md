# Make Evidence-Level Mastery the Core Learning Contract

The foundation path will end with a performance-based gate, and the core path will progress through explanation, source and runtime tracing, bounded modification, and evidence-level mastery. A graduate must be able to state invariants, identify failure paths, design deterministic oracles, and describe the limits of test evidence, while using the current branch as the executable baseline and retracing another xv6 version with guidance.

## Considered Options

- Stop at conceptual explanation.
- Require source tracing but no implementation work.
- Require bounded implementation changes and ordinary regression tests but no explicit reasoning about evidence.

## Consequences

Each core topic needs observable outcomes along the capability ladder, but early units need not reach the final level immediately. Assessment must include artifacts such as traces, state-transition accounts, patches, invariants, failure cases, and oracle explanations rather than relying only on reading completion or successful boot.
