# Use Bounded Units on One Shared Learning Graph

A learning unit will have one primary observable outcome and one independently reviewable exit artifact, even when its source trace crosses several files. The seven macro-stages group these units rather than becoming seven monolithic chapters, and both zero-prerequisite and prepared learners join one shared graph after completing or passing the foundation gate.

## Considered Options

- Make each source file or kernel subsystem one unit.
- Make each macro-stage one long chapter.
- Maintain separate beginner and fast-track copies of the curriculum.

## Consequences

Unit boundaries follow reviewable learning outcomes rather than source layout. Prepared learners may skip foundation instruction only by satisfying the same performance gate; downstream core units and assessments are identical for both entry routes.
