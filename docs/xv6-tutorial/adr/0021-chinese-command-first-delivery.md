# Use Chinese Prose and a Command-First Environment

The standalone tutorial will use Chinese instructional prose while preserving exact English source symbols, commands, specification names, and established technical terms. Linux or WSL, the command line, the repository toolchain, and QEMU are the supported core environment; GDB is taught from first use, while VSCode remains an optional interface rather than a prerequisite.

## Considered Options

- Maintain complete Chinese and English copies.
- Require VSCode as the primary learning interface.
- Formally support several host operating systems in the core path.

## Consequences

Terminology must remain consistent and searchable by its source spelling. Core instructions use reproducible commands and do not rely on IDE state; alternative hosts and editors may be documented as non-blocking extensions.
