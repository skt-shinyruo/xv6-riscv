# Let Implementation Coverage Set the Curriculum Size

The curriculum will not target a fixed semester length or total study time. Its scope will grow to cover the executable baseline progressively, because omitting implementation areas to meet a timebox would conflict with the goal of turning the repository's complete implementation reference into a teaching resource.

## Considered Options

- Limit the core path to a short survey and leave uncovered implementation areas only in the reference layer.
- Fit the curriculum to a conventional semester and treat excess material as optional.

## Consequences

The curriculum needs explicit progress markers and dependency information even though it cannot promise a fixed completion time. Individual learning units must remain bounded, and adding implementation coverage may add units without forcing existing units to duplicate reference material.
